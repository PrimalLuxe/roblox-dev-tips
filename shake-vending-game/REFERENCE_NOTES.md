## Distinct identity retained

The game remains **shake public vending machines → physically reveal RNG collectibles → fill a catalog → unlock avatar cosmetics/auras → showcase/trade/flex**. The retention spine is still **RNG → Collection → Avatar → Social Economy**, not pets, rebirths, or a tycoon factory.

## Current design decisions

- Warm cream/product-label UI language rather than generic dark-neon simulator panels.
- Machine neighborhoods differ by commercial theme and donor composition, not recolor alone.
- Rare presentation uses truthful obtained-roll odds and separately labels natural-pool odds when Lucky Meter changes the conditional pool.
- World events change machine/world state; Jammed exposes a cooperative physical progress readout rather than only a generic notification.
- Showcase uses six editable slots plus an automatic rarest-item centerpiece and a single distance-bounded client animation loop.
